# GGSC Frontend

This project is built with **React 19**, **Vite**, **TypeScript**, and **Tailwind CSS**.

## Getting Started

### 1. Install dependencies

```bash
npm install
```

### 2. Start the development server

```bash
npm run dev
```

Open [http://localhost:5173](http://localhost:5173) in your browser.

### 3. Build for production

```bash
npm run build
```

### 4. Preview the production build

```bash
npm run preview
```

### 5. Linting

```bash
npm run lint
```
